## PortWatch VI 3.0.1 — Expressive

Four distinct Material 3 Expressive-inspired designs, each with square, compact and large layouts.

- Dynamic Monet palette and corrected secondary tonal background.
- Adaptive vector launcher icon with monochrome themed icon on Android 13+.
- Live preview, GPU filters, cached statistics and configurable refresh.
- Russian news translation with fallback.

**Install:** download `PortWatch-VI-3.0.1.apk`, open the app and add a widget. Android 8+; Monet requires Android 12+.

This is the exact debug APK from [successful build 45724331303](https://github.com/BadKiko/PortWatchAndroidWidget/actions/runs/45724331303). If updating from a differently signed debug build, uninstall the old version first. Device rendering may vary.

A temporary project for the porting race; it will have served its purpose when the race is over.
